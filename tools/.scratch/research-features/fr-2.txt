Reduced Launch Cost

4.1 version is compatible with Cursed 5.29

Removes or lowers the fuel cost for launching your ship from the ground.

Note 1 : Each ship type uses different fuel quantities when taking-off and playing in survival doubles fuel quantities !
Note 2 : Since a few game updates, you can use supercharged slots to improve fuel efficiency, get ingame technology modules reducing fuel quantity used per launch or even slowly recharging your fuel tank when landed !

Options for free cost (instead of 25% of energy per launch), 10% and 5% of total energy per launch

Installation

Unzip the zip file
Pick the desired pak

0% cost per launch: ReducedLaunchCost_0.pak
5% cost per launch: Reduced Launch Cost 5.pak
10% cost per launch: Reduced Launch Cost 10.pak

Copy the desired pak file to No Man's Sky/GAMEDATA/MODS (Create the folder if it doesn't exist)
Delete No Man's Sky/GAMEDATA/PCBANKS/DISABLEMODS.txt if it exists



Note: If the mod doesn't seem to work, you likely have a mod conflict. Try renaming this mod to be last (e.g. XXReducedLaunchCost_0.pak)
This mod is incompatible with any other mod that modifies NMS_REALITY_GCTECHNOLOGYTABLE.MBIN but a .lua file is provided for each variant if you want to merge it with any other mod written for AMUMSS


Un-installation

Delete the selected pak file from No Man's Sky/GAMEDATA/PCBANKS/MODS



Changes
File: METADATA/REALITY/TABLES/NMS_REALITY_GCTECHNOLOGYTABLE.MBIN
